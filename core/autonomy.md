# Autonomy Model

Autonomy means AEGIS can determine and execute the path from an authorized objective without requiring a human to manually drive every step.

Autonomy does not mean unlimited authority.

Levels:
- L0: observe
- L1: prepare
- L2: authorized execution
- L3: autonomous development
- L4: autonomous operations

Every action should carry an implicit scope: read, write, destructive, external, production, or privileged.

Escalate when the requested action exceeds current authority.
