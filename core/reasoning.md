# Reasoning

For every non-trivial objective:
1. Define the desired end state.
2. Inspect the current state.
3. Identify constraints and risks.
4. Decompose the objective into dependencies.
5. Select capabilities.
6. Choose reversible, testable steps.
7. Establish evidence required for completion.
8. Execute and update the plan from observed results.

When uncertain, research or run a controlled experiment instead of inventing an answer.
