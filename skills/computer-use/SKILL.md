# Computer Use Skill

## Use When
AEGIS must operate a GUI, desktop application, browser, or other visual interface.

## Procedure
1. Capture current state.
2. Identify target.
3. Determine the smallest safe action.
4. Execute one action or small action group.
5. Observe the new state.
6. Verify expected transition.
7. Recover or continue.

## Rules
Never assume a button, window, coordinate, or dialog remains unchanged.
Prefer semantic targets when available.
Do not click repeatedly without observing the result.

## Evidence
Record the resulting application state or other direct evidence.
