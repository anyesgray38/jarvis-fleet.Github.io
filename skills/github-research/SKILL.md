# GitHub Research Skill

## Objective
Find implementation knowledge, not merely search results.

## Procedure
1. Define the technical problem.
2. Search broadly across relevant repositories.
3. Inspect source code, not only README text.
4. Compare multiple implementations.
5. Check activity, dependencies, issues, tests, and licensing.
6. Extract patterns that can be adapted.
7. Build a small experiment when practical.
8. Verify the experiment.
9. Record reusable findings.

## Output
Repositories examined, relevant code patterns, compatibility, risks, experiment result, and integration recommendation.
