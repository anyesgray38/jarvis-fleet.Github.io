# Known Failure Modes

## Stale State
Cause: acting on an outdated screen, file, branch, or process state.
Mitigation: re-perceive before consequential actions.

## False Completion
Cause: treating an issued action as proof of success.
Mitigation: inspect resulting state and verify.

## Context Overload
Cause: loading all memory for every task.
Mitigation: use memory/index.md and load only relevant files.
