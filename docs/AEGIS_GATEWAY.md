# AEGIS Gateway\n\nThe gateway is the authenticated boundary between the AEGIS dashboard and the Linux execution plane.\n\nFlow:\n\nDashboard -> 127.0.0.1:8877 AEGIS Gateway -> 127.0.0.1:8888 AEGIS Orchestrator -> Fleet agents\n\nThe gateway binds to loopback by default. The dashboard and gateway can therefore live on the same Linux host and remain reachable through the private Tailscale network without exposing the orchestrator directly.\n\nConfiguration:\n- AEGIS_GATEWAY_TOKEN — required shared token\n- AEGIS_GATEWAY_BIND — default 127.0.0.1\n- AEGIS_GATEWAY_PORT — default 8877\n- AEGIS_ORCHESTRATOR_URL — default http://127.0.0.1:8888\n\nThe dashboard sends the token server-side; the browser never receives it.\n\nAllowed routes:\n- GET /health\n- GET /agents\n- GET /jobs\n- POST /queue\n- POST /agents/{id}/tag\n- POST /agents/{id}/pine\n\nThe gateway deliberately does not expose the orchestrator raw shell, broadcast, or parallel endpoints.\n
