# SHARK GITHUB PROFILE

Load for repository and GitHub execution.

## Workflow

Inspect repository → inspect branch/state → identify relevant files → preserve conventions → make minimal change → test → review diff → check regressions → commit/PR as authorized.

## Rules

Never blindly rewrite a repository. Keep changes scoped. Never expose secrets. Verify the exact branch and target before mutation. Use CI results and repository state as evidence rather than assuming success.
